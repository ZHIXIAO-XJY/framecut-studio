拆解方法论 · P0–P7

工具只负责“看见”和“记账”，判断留给导演
P0 / PROBE

探针与素材准备

确认时长、分辨率、音轨与格式。本页在载入视频时自动完成并写入附录。

P1 / SAMPLE

固定频率采样

快拆 0.5 fps（2s/帧），精拆 1 fps（1s/帧）。用 Canvas 精确定位时间点，不靠截图猜。

P2 / TIMELINE

建立时间轴

每一帧就是一个带时间码的分镜单元，卡片顺序即播放顺序，不破坏原始时间关系。

P3 / EVIDENCE

画面与字幕证据

支持导入 SRT / 手动台词，按时间挂载；台词优先于模型猜测。

P4 / QC

质检前置

抽帧后立即做黑屏、模糊、过曝、字段完整与相邻帧相似度校验，问题在写作前暴露。

P5 / NOTE

五维补充

画面描述、台词、运镜、景别、情绪/表演提示，按卡片补齐，可逐镜 AI 重解读。

P6 / FIX

局部修正

单镜质检、重新取帧、人工标记通过，只更新当前卡片，不重跑整条时间轴。

P7 / DELIVER

交付与复核

Markdown 便于协作，PDF 用于客户交付；封面、摘要、分镜表、附录一页不缺。

六条铁律
  1. 台词零清洗：保留“呃 / 哎 / 嗯 / 呀 / 嘘 / 哦 / 哼”，它们是真实感与人物分配的证据。
  2. 眼神必须具名：写清“谁看向谁的具体部位 + 停留”，禁止“看向对方”。
  3. 表情写变化轨迹：按 [起] → [中] → [末] 推进，不写单个静态形容词。
  4. 语气写声音质感：音高、音量、语速、气息、重音、停顿，至少三项。
  5. 说话人过校验链：字幕 / 转录 / 口型 / 剧情因果交叉确认，不靠感觉分配。
  6. 身份三重锁定：面孔 + 造型 + 场景关系，防同脸复用与中途换装。
关于「按固定频率抽帧」：本页严格按所选模式生成采样点，不做“智能跳帧”或时间轴压缩。要理解剪辑节奏，先保证时间轴没有被算法改写。
